Названия кнопок в руководствах соответствуют интерфейсу на момент подготовки.
В руководстве по вебинарам используются демонстрационные данные. Проверка
webinar-результатов в CRM остаётся отдельным этапом; PDF не подтверждает её
завершение.

Готовые инструкции хранятся здесь. ТЗ находятся в
[specifications](../specifications/README.md), технические правила эксплуатации —
в [OPERATOR_GUIDE.md](../OPERATOR_GUIDE.md). Локальные исходники PDF, снимки и
промежуточные рендеры сохранены в игнорируемой папке `tmp/pdfs`.
