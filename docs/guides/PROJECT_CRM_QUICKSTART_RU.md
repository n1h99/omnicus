# Как создать проект Omnicus и подключить CRM

Проверено по интерфейсу **03.11.2026**.
[Каталог инструкций](README.md).

Для подключения нужны права на создание проекта в Omnicus и управление
интеграциями, а также доступ администратора к выбранной CRM. Пример ниже
относится к Cyber Pulse с разделом **Integrations → Omnicus**.

1. Откройте **Projects → Create project**. В **Name** укажите название, в
   **Slug** — уникальное имя строчными латинскими буквами, цифрами и дефисами,
   например `new-project`. Укажите **Timezone** в формате IANA, например
   `Asia/Baku`, и **Locale**; описание необязательно. Нажмите **Create**.
2. Выберите созданный проект и откройте **Connections → CRM integration**.
3. Укажите **CRM project ID**. Используйте идентификатор нужного проекта CRM:
   он должен совпадать с полем **CRM project ID** в её разделе интеграции.
   Для базового подключения **Default pipeline** и **Default stage** можно
   оставить пустыми, **Field mapping (JSON)** — `{}`. Включите
   **Enable CRM integration** и нажмите **Save configuration**.
4. Нажмите **Generate pairing code**. Скопируйте **Omnicus API URL** и
   **Pairing code**. Код одноразовый и действует 10 минут.
5. В выбранной CRM откройте **Integrations → Omnicus**. Вставьте URL и код,
   проверьте совпадение **CRM project ID** и нажмите **Pair Omnicus**.
6. Обновите страницу **CRM integration** в Omnicus и нажмите
   **Test connection**. Успех подтверждается сообщением
   **CRM connection verified.** На стороне CRM также доступен
   **Test connection**; после подключения отображается статус **ACTIVE**.

Каждый новый проект подключается отдельно. Создание проекта и pairing не
копируют каналы, контакты и сценарии из другого проекта и не запускают
массовый импорт исторических лидов.

Если **Create project** или **CRM integration** не отображается, администратор
должен выдать соответствующие права. Если код истёк, создайте новый и повторите
подключение с ним.
