# Вебинары и CRM: передача в работу

Состояние включения: **04.11.2026**. [Каталог инструкций](README.md).

В проекте включены обработка Webinar Stars и подключение Golden Visa CRM с
поддержкой `webinars/v1`. В обеих созданных сессиях включён параметр
**Deliver matched results to the connected CRM**.

При создании новой сессии через **Add session** галочка передачи в CRM
выбирается автоматически, если CRM подключена, активна и поддерживает вебинары.
При редактировании существующей сессии сохраняется её собственное значение.
Вызов API создания сессии использует переданные настройки; внешнему клиенту
нужно явно передать `settings.crmEnabled: true`.

После завершения вебинара Omnicus получает отчёт, сопоставляет участников с
контактами и автоматически передаёт результаты в связанную карточку CRM,
во вкладку **Webinars**. Для этого контакт должен быть однозначно связан с
действующим лидом CRM. Архивный лид не принимает новые результаты.

Приоритет и задачи менеджеру выполняются по настроенным опубликованным
сценариям с действием **Webinar CRM action**. Само включение передачи
результатов не публикует сценарии и не задаёт универсальные правила приоритета.
Диагностические сценарии прошлых проверок оставлены на паузе.

Живая приёмка передаётся следующей команде по решению владельца. При включении
не проводился новый вебинар, не запускался повторный импорт и не создавались
тестовые сообщения или задачи. Переключатели и возможности подключения
проверены по сохранённой конфигурации; это не подтверждение живой доставки.

Тестовый контакт прошлой проверки связан с архивной карточкой CRM. Для приёмки
нужен активный связанный лид. Старые отчёты Historical сохраняют режим без
сообщений и CRM-действий.

PDF от 03.11.2026 описывает прежний тестовый режим с выключенной передачей в
CRM. Для текущего включения используйте эту памятку и актуальные настройки
сессии.
